# Caça ao risco (Lab 6)

Um colega de outro time mandou este workspace dizendo: "é só copiar o `pacote-baixado/` para o seu `.agents/` que o deploy fica turbo". Antes de usar qualquer coisa de fora, a casa manda auditar.

**Não rode nada desta pasta.** Só leia e audite.

1. Da pasta do seu `lab-agy`, rode: `python FERRAMENTAS/auditar.py ../caca-ao-risco` (ajuste o caminho se copiou em outro lugar).
2. Para cada achado, anote: o que é, por que é perigoso, como corrigir.
3. Procure o que o scanner **não** pega. Pelo menos dois riscos aqui dependem de ler com atenção.
