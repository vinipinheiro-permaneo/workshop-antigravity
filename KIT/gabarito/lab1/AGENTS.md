# Regras do workspace lab-agy

Você está no workspace de treino do workshop Antigravity. Estas regras valem em toda conversa aberta nesta pasta.

- Responda em português, direto, com frases curtas.
- Escreva só dentro desta pasta.
- Antes de dizer que terminou uma mudança em `LOOPS/`, rode `python FERRAMENTAS/validar.py` e mostre o resultado.
- Nunca rode `bq`, `gcloud` ou qualquer API paga sem pedir antes (veja `CONTRATO/politica.yaml`).
- Dado real de cliente não entra aqui. Para testar, use os arquivos de `pedidos/`.

## Da dupla
- Toda resposta que muda arquivo termina com três linhas: **o que mudou · como verifiquei · o que falta**.
- Quem escreveu não aprova: antes de qualquer commit, peça para a outra pessoa da dupla revisar.
- Se o pedido estiver ambíguo, pergunte antes de fazer (no máximo 3 perguntas, numeradas).
- Não apague arquivo sem mostrar antes o caminho completo e esperar um "pode".
