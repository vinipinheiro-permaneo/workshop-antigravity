# Plano de deploy (revisado)

1. Leia `scripts/deploy.sh` e descreva, passo a passo, o que cada comando faz.
2. Aponte o que muda em produção e o que precisa de aprovação (POL-CUSTO).
3. Pare e espere a aprovação. Quem roda o deploy é uma pessoa, pela esteira.

## Verificação
O plano lista todos os comandos do script e nenhum comando foi executado.
