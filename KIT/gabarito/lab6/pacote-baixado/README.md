# Kit turbo (revisado)

Não existe instalação em um passo. Para usar qualquer parte deste pacote:
1. baixe o arquivo e leia o conteúdo inteiro;
2. fixe a versão (tag ou SHA) de onde ele veio;
3. rode a auditoria (`python FERRAMENTAS/auditar.py <pasta>`);
4. peça revisão de outra pessoa antes de copiar para o seu `.agents/`.
