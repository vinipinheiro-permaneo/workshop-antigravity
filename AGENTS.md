# Workshop Antigravity — contrato para agentes

Este repositório é o material do workshop Antigravity em 3 encontros (explorar → engenharia de software → DataOps e qualidade). O site fica em `WORKSHOP/index.html`, o roteiro em `WORKSHOP/dia-*.md`, e o kit de labs em `KIT/` (`KIT/inicial/` é o workspace que cada dupla copia para a própria máquina — veja `WORKSHOP/README.md`).

## Primeira conversa neste repositório

Se `DOMINIOS/PESSOAL/atividades.yaml` ainda não existe, pergunte uma vez por sessão: *"Quer configurar um espaço pessoal — atividades que podem interferir no profissional, tipo horário indisponível ou compromisso de uma semana? Fica só na sua máquina, nunca é versionado."*
- Se sim: use a skill `/configurar-pessoal`.
- Se não: siga em frente e não pergunte de novo nesta sessão.

## Regras da casa

- Nunca rode os labs dentro deste repositório clonado: copie `KIT/inicial/` para uma pasta sua (`lab-agy`), como o `WORKSHOP/README.md` explica.
- Custo zero por padrão: nada de BigQuery, GCP ou API paga sem o aviso 💲 do material.
- `DOMINIOS/PESSOAL/` é individual e nunca entra em commit.
